# CodeAlpha Data Visualization

## Project Overview

This project visualizes student performance using Python. It explores students' mathematics, reading, and writing scores through charts and graphs.

## Dataset

**Dataset Name:** Students Performance in Exams

The dataset contains students' scores and information about gender and parental education.

**Dataset Source:** [Kaggle — Students Performance in Exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab

## Visualizations

Five visualizations were created:

1. Average Student Scores by Subject
2. Distribution of Mathematics Scores
3. Average Scores by Gender
4. Correlation Between Student Scores
5. Student Performance by Parental Education

## Key Objectives

* Compare student scores across subjects.
* Understand the distribution of mathematics scores.
* Compare academic performance by gender.
* Explore correlations between subject scores.
* Analyze scores across parental education levels.

## Conclusion

This project demonstrates how Python visualization libraries can transform raw data into meaningful charts and help identify patterns in student performance.

## How to Run

1. Download the Jupyter Notebook from this repository.
2. Open it in Google Colab or Jupyter Notebook.
3. Upload `StudentsPerformance.csv` when prompted.
4. Run all cells to generate the visualizations.
